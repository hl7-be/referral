### Common referral prescription model

`BeReferralServiceRequest` is the **common referral prescription model** — the shared structure that every referral prescription builds on. Specific use cases (a [care proposal](StructureDefinition-care-proposal.html), a telemonitoring request, a re-order) are expressed as *specializations* that derive from it and add only their own rules.

See the [Data models](datamodels.html) page for the full model hierarchy and how the specializations relate.
